## 💪 FITLOG

**FITLOG** is a modern fitness platform where users can explore exercises, discover workout routines, and create personalized workout plans with duration and calorie tracking.

**Live Website |** [Fitlog](https://fitlog.surge.sh/)

---





### 📝 Project Overview

FITLOG is a responsive single-page application built with React. It is organized around three core experiences:

- **Workouts** – explore exercises and routines.
- **My Plan** – assemble and manage your personal training plan.
- **Dashboard** – review your activity and stay consistent.

The interface uses a dark palette with lime accents (`#C6FF00`) for a bold, modern, performance-oriented feel across mobile, tablet, and desktop.

---




### ✨ Key Features

- **Workout Library** – browse and discover exercises in one place.
- **Personal Plans** – create and manage your own training plan.

### 🔌 Data Integration

FITLOG runs on a lightweight, backend-free data layer, which keeps setup simple and development fast.

- **Data source:** A static JSON file, `public/exercise-data.json`, containing generated sample exercise data.
- **Data fetching:** Loaded on the client with the Fetch API from the public folder.
- **State management:** React hooks for application state.

---




### 🏋️ Workout Plan Management

FITLOG provides a simple workout planning experience that allows users to organize their selected exercises.

- **Add Exercises** — Add preferred exercises to personal workout plans.
- **Duplicate Checking** — Validate existing exercises before adding new ones.
- **Manage Plans** — View selected exercises in the My Plans section.
- **Workout Overview** — Review planned exercises and their workout information.
